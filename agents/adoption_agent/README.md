## Cases

- primary: conservative regional bank, unknown control readiness and local performance.
- contrast_1: identical technology, application, capabilities, and evidence; only risk tolerance changes. A justified unchanged category is acceptable; explain differences in timing or willingness to experiment without inventing controls.
- contrast_2: leading-edge bank with hypothetical control readiness and successful limited offline evaluation explicitly stipulated. Tests a conditional progression to a bounded experiment, not an actual bank result. This contrast changes more than posture and cannot isolate posture's effect.
